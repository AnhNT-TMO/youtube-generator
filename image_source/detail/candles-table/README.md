# Nến, bánh & cốc (Candles, treats and drinks)

Nhóm vibe: **detail** (Cận cảnh). Đích: 20 cảnh → 20 ảnh → 20 video 10 s.

## Là gì

Cận cảnh nến, vòng hoa Advent, bánh quy, cacao, trà: cầu nối ấm.

## Vibe

- Ánh sáng (`look`): `interior-evening` · thời điểm `night` · bảng màu `warm-gold`
- Không gian: `indoor`, cỡ cảnh `macro`, tuyết `window`, nhịp `calm`
- Máy quay mặc định: `push-in` về the candles (out-and-back, kết thúc đúng khung đầu)
- Ghép cùng: mọi nhóm (cầu nối)
