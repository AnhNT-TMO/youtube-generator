# Sảnh khách sạn (Grand hotel lobby)

Nhóm vibe: **grand** (Sang trọng). Đích: 20 cảnh → 20 ảnh → 20 video 10 s.

## Là gì

Sảnh khách sạn cổ: cây thông cao, đèn chùm, cầu thang đá, sàn bóng.

## Vibe

- Ánh sáng (`look`): `interior-bright` · thời điểm `night` · bảng màu `white-gold`
- Không gian: `indoor`, cỡ cảnh `vista`, tuyết `none`, nhịp `calm`
- Máy quay mặc định: `crane-up` về the tall tree (out-and-back, kết thúc đúng khung đầu)
- Ghép cùng: village (đêm), home (trang viên), detail (nến)
