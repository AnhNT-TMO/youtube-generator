# Phòng khiêu vũ (Christmas ballroom)

Nhóm vibe: **grand** (Sang trọng). Đích: 20 cảnh → 20 ảnh → 20 video 10 s.

## Là gì

Phòng khiêu vũ trống: đèn chùm, gương, cây thông, sàn gỗ bóng.

## Vibe

- Ánh sáng (`look`): `interior-bright` · thời điểm `night` · bảng màu `white-gold`
- Không gian: `indoor`, cỡ cảnh `vista`, tuyết `window`, nhịp `calm`
- Máy quay mặc định: `slide` về the ballroom (out-and-back, kết thúc đúng khung đầu)
- Ghép cùng: village (đêm), home (trang viên), detail (nến)
