# Thư viện lớn (Grand library)

Nhóm vibe: **grand** (Sang trọng). Đích: 20 cảnh → 20 ảnh → 20 video 10 s.

## Là gì

Thư viện cổ nhiều tầng kệ, cầu thang xoắn, đèn bàn xanh, cây thông.

## Vibe

- Ánh sáng (`look`): `interior-evening` · thời điểm `night` · bảng màu `warm-gold`
- Không gian: `indoor`, cỡ cảnh `vista`, tuyết `window`, nhịp `calm`
- Máy quay mặc định: `crane-up` về the tall shelves (out-and-back, kết thúc đúng khung đầu)
- Ghép cùng: village (đêm), home (trang viên), detail (nến)
