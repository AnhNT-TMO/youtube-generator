## Vibe

- Ánh sáng (`look`): `twilight` · thời điểm `twilight` · bảng màu `warm-gold`
- Không gian: `outdoor`, cỡ cảnh `street`, tuyết `falling`, nhịp `calm`
- Máy quay mặc định: `drone` về the lit house (out-and-back, kết thúc đúng khung đầu)
- Ghép cùng: detail, magic, cozy-loop; village qua cảnh hiên/cửa sổ
