# Quả cầu tuyết & mô hình (Snow globes and miniatures)

Nhóm vibe: **magic** (Phép màu Giáng sinh). Đích: 20 cảnh → 20 ảnh → 20 video 10 s.

## Là gì

Quả cầu tuyết, làng tí hon, tàu mô hình; cận cảnh.

## Vibe

- Ánh sáng (`look`): `interior-evening` · thời điểm `night` · bảng màu `warm-gold`
- Không gian: `indoor`, cỡ cảnh `macro`, tuyết `none`, nhịp `calm`
- Máy quay mặc định: `push-in` về the snow globe (out-and-back, kết thúc đúng khung đầu)
- Ghép cùng: home (phòng trẻ em), detail, village (lễ hội)
