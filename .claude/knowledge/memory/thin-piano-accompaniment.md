Christmas ambient covers (Mureka prompts in styles.md, generated by mureka_source.py prompt_text): piano is the only lead; left hand holds one low note or open fifth per bar, nothing in between. Prompt follows Mureka's own guide order (identity → piano role → support colour by role → structure → texture); instruments named positively and never named to exclude them (CEO 2026-10-09). Later 10-09 the CEO amended it: each style has exactly three instruments (grand piano + one bed: soft pad / low strings / airy string pad + one accent: celesta / vibraphone / glockenspiel, no sleigh bells), a generic line `STRICTLY FORBIDDEN: any instrument not in this list.`, and no song title in the prompt (the Remix upload carries the melody). Then (same day, CEO heard Silent Night m013 v3/v4): mood always warm + joyful like v4 (v3 muddy, gloomy); piano clear and dry (bright round notes struck and released cleanly, light pedal, short decay), no ambient/reverb/pedal-hold words; always in the input melody's key and notes. PROMPT_VERSION v4-bright-joyful. The 3-instrument list worked: no extra instruments in m013. Guitar = warning flag (htdemucs_6s) for the CEO to listen.

**Update 2026-10-09 (latest, supersedes the prompt wording above):** the CEO wrote a chamber-trio prompt form: `Minimal intimate chamber trio.`, then piano as clear lead plus bed and sparse accent, then an explicit list of no rhythm section/beat/drums/kick/snare/hi-hat/cymbals/toms/shaker/tambourine/sleigh bells/rhythmic percussion and no bass, guitar, brass, woodwinds, choir or vocals, then the accent never plays a rhythmic pattern, then key + BPM (no meter) with gentle/warm/bright/intimate, sparse, dry close piano, then `Only piano, <bed> and sparse <accent>.` It was tested on Lo, How a Rose m020 (V9): both takes had no drums and no extra instruments; the CEO called it the best prompt so far and had it applied to all songs (PROMPT_VERSION v6-chamber-trio; styles.md keeps paragraphs; STYLE headers separate styles). This form names excluded instruments, which overrides the old never-name rule.
